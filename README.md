## ✨ Features

### Core Features
- 🔐 **Secure Authentication** - JWT with bcrypt password hashing
- 📊 **Interactive Dashboard** - Chart.js visualizations
- 💰 **Budget Management** - Set monthly budgets with real-time alerts
- 📝 **Expense Tracking** - CRUD operations with category selection
- 👤 **User Profile** - Manage personal information
- 🔒 **Protected Routes** - Frontend + Backend security

### UX Enhancements
- 👁️ **Password Visibility Toggle** - Show/hide password on login/register
- 📱 **Responsive Design** - Works on all devices
- ⚡ **Fast Performance** - <300ms API response time
- 🎨 **Modern UI** - Clean, intuitive interface

## 🛠️ Tech Stack

### Frontend
- **React 19** - UI library
- **React Router DOM v7** - Navigation
- **Chart.js** - Data visualization
- **Axios** - HTTP requests
- **CSS3** - Styling

### Backend
- **Node.js** - Runtime
- **Express.js** - Web framework
- **MongoDB Atlas** - Cloud database
- **Mongoose** - ODM
- **JWT** - Authentication
- **bcryptjs** - Password hashing

## 📦 Installation

### Prerequisites
- Node.js (v16 or higher)
- npm (comes with Node.js)
- MongoDB Atlas account (free) or local MongoDB

### Step 1: Clone the Repository

git clone https://github.com/YOUR_USERNAME/fintrack.git
cd fintrack

# Install all dependencies (root, backend, frontend)
npm run install-al


# Start both backend and frontend
npm run dev
